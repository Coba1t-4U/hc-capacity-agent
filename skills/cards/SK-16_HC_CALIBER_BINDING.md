# HC.CALIBER.BINDING@1.0.0  口径绑定校验

**目的**：回答"这个结论现在还能不能引用"——判断结论所依赖的计算版本、口径与参数是否已经变化。

**适用范围**：全部业务场景；只读技能；任意权限级别（含 L0 只读）。

**是否必须专业引擎**：否

**输入**：
- `run_dir`（路径）（必填）

**前置条件**：
- 运行目录里至少存在 `manifest.json` 或 `results/run_summary.json`

**执行步骤**：
1. 从产物重建凭证 `B = {F, v_calc, Θ, γ}`：
   - `F` 数据指纹：`manifest.input_digest` 或 `run_summary.input_digest`
   - `v_calc` 计算版本：引擎标识与版本、接口、Python 版本、Agent 版本
   - `Θ` 口径：规则包、拓扑版本、技能版本、快照 id
   - `γ` 参数：同时率、裕度、规则文件哈希、搜索方法、时间片数
2. 取当前环境凭证（同一套字段）。
3. 逐分量比对；**当前环境取不到值的键不参与比对**（取不到 ≠ 变了）。
4. 输出差异或"仍然成立"。

**输出**：
- `ok`（布尔）、`available`、`reason`（一句话）、`diffs[]`（逐分量差异）、`digest`（凭证短哈希）

**异常**：
- 产物缺失 → `available=false`，说明无法重建。（**不返回 ok=true**）
- 当前环境取不到任何当前值 → 视为无变化，但 `reason` 中说明局限。

**证据**：凭证哈希 `digest` 可写进报告与审计链。

**边界**：
- 校验的是**口径一致性**，不是**结论正确性**。
- 不做数据指纹的重新采集（那需要原始输入包；本技能只比对产物里记录的指纹）。
- 不自动作废文件、不删除任何产物。

**测试样例**：
| 场景 | 期望 |
|---|---|
| FD002 原样 | `ok=true`，`reason` 含"仍然成立" |
| 复制后改 `config/rules.yaml` 内容 | `ok=false`，差异定位到"参数"分量，含 `rules_yaml_sha` 前后值 |
| 不存在的目录 | `available=false`，原因明确 |
| 缺 manifest 与 run_summary | `available=false` |
