# 配网承载力业务流（八段闭环）

> 这里是业务口径的**原文参照**，用来对齐"业务上应该怎么做"。
> 代码里各环节的实现状态见 `hc_agent/business_flow.py`（以代码为准）。
> 面向：分布式光伏等分布式电源接入配电网的承载力。

## 一、整体业务流

### 1. 基础数据收集与治理

| 类别 | 内容 |
|---|---|
| 网架数据 | 变电站、10kV 线路、配变、台区的拓扑关系与设备参数（导线型号、变压器容量等） |
| 运行数据 | 负荷曲线、电压、电流、功率因数、典型日与极端日数据 |
| 电源数据 | 已并网与已受理未并网的分布式电源容量、类型、位置 |
| 规划数据 | 近期负荷增长、网架改造与新增电源规划 |
| 数据来源 | 营销系统、PMS（生产管理系统）、调度/D5000、用采系统、GIS |

### 2. 评估边界与约束条件设定

- 设备热稳定约束：线路与变压器载流能力
- 电压偏差约束：接入后节点电压不越限
- 短路电流约束：不超过开关设备遮断能力
- 反向负载/倒送约束：变压器与上级电网反送功率限制
- 电能质量约束：谐波、电压波动等
- 继电保护适应性约束

### 3. 承载力计算分析

- 按「台区 → 10kV 线路 → 变电站（主变） → 区域电网」**逐级**计算
- 基于典型场景（大发小用、小发大用等）做潮流计算与仿真
- 取各约束下的**最小值**，作为该单元的最大可接入容量
- 扣除已接入与已受理容量，得到**剩余可开放容量**

### 4. 结果分级

| 等级 | 含义 | 处理 |
|---|---|---|
| 绿 | 有较充足接入空间 | 可正常接入 |
| 黄 | 接入空间有限 | 需谨慎，可附带条件（配储能或调节能力） |
| 红 | 接入空间不足 | 原则上暂停或限制接入，需先改造 |

### 5. 结果发布与公示

- 通过省级或地市电网企业平台（如网上国网）向社会公开
- 定期更新（通常按季度或年度，条件变化时临时更新），并报送能源主管部门

### 6. 业务应用（接入管理）

- 接入申请受理时，以承载力结果作为判断依据
- 出具接入系统方案与答复意见，引导项目选址、规模与接入电压等级
- 红区项目暂缓或要求配套提升措施，同时为规划部门提供依据

### 7. 提升措施与改造

| 类型 | 手段 |
|---|---|
| 网架改造 | 线路增容、变压器扩容、新建线路与变电站 |
| 调节资源 | 储能、无功补偿、有载调压 |
| 管理手段 | 柔性控制、可观可测可调可控改造、出力限制策略 |

改造完成后，重新评估并调整区域等级。

### 8. 动态更新与闭环

- 新增并网、负荷变化、改造投运后，数据回流并重新计算
- 形成「评估 → 发布 → 应用 → 改造 → 再评估」的持续闭环

## 二、一句话流程

数据采集治理 → 约束建模 → 分层计算 → 红黄绿分级 → 发布公示 → 接入审批应用 → 提升改造 → 数据更新再评估

## 三、口径说明

- 具体做法因地区与电网企业而异，各省评估导则与发布频次有差别。
- 本系统的**分级**是单算例判定结果，**不等同于**省公司对外发布的区域承载力等级。
- 本系统不代做未实现的环节（发布公示、工单流转等），缺什么就在
  `hc_agent/business_flow.py` 里如实标 `absent` / `partial`。
