# 配网承载力算例 · 双台区对比

一条 10 kV 馈线带**两个台区**，一个正常、一个末端电压越限。
用来演示"同一时刻、不同台区，承载力结论可以完全不同"。

## 拓扑

```
变电站 10.5 kV (sourcebus → MVBUS)
  ├ L_MV_1  1.00 km ─ MV_N1 ─┬ L_BR_T1 0.20 km ─ T1 400 kVA
  │                          │   低压 0.15 km ── 负荷 200 kW（无光伏）
  │                          │   → 正常
  └ L_MV_2  1.00 km ─ MV_N2 ─┴ L_BR_T2 0.30 km ─ T2 200 kVA
                              低压 0.90 + 0.70 = 1.60 km
                              负荷 80 kW + 光伏 220 kW
                              → 末端电压约 1.13 pu，越上限
```

主干 LGJ-120｜分支 LGJ-70｜低压 YJV-4×185

## 文件

| 文件 | 内容 |
|---|---|
| `Master.dss` | 建电路 + 求解设置 + 按序 Redirect |
| `LineCodes.dss` | 三种导线型号参数 |
| `Grid.dss` | 10 kV 主干与台区分支 |
| `Transformers.dss` | 两台配变 + 低压线路 |
| `Loads.dss` | 三个负荷点（合计 280 kW） |
| `PV.dss` | 光伏 220 kW（含容量标定记录与两层净功率说明） |

## 预期结果（已跑过，可核对）

| 项目 | 数值 |
|---|---|
| 收敛 | 是，4 次迭代 |
| 母线 / 支路 | 11 / 10 |
| 总负荷 | 280 kW |
| 分布式电源 | 220 kW |
| 源侧交换 | **−83.91 kW**（负数＝仍在受电） |
| 网损 | 23.91 kW（占负荷 8.54%） |
| **最高电压** | **1.1317 pu @ LV_T2_N2**（越 1.10 上限 +0.0317） |
| 最低电压 | 0.9865 pu @ LV_T1_N1（台区1，正常） |
| 电压越限母线 | **1 个**：LV_T2_N2 |
| 设备过载 | **0 个**（最高负载率 79.18% @ LV1_A） |

## 这个算例想说明什么

**设备没满，电压先满。**

- 最高负载率只有 79.18%，变压器和线路都没过载；
- 但台区2 末端电压已到 1.1317 pu，超了 1.10 上限。

所以"还能不能接"不能只看设备容量，电压往往是先到限的那个。

## 两层"净功率"别混（常见误读）

| 口径 | 数值 | 说明 |
|---|---|---|
| 台区2 内部 | 220 − 80 = **约 140 kW 净外送** | 要穿过 T2 与 1.6 km 低压线；140/200=70%，T2 不过载 |
| 整条馈线 | 源侧 **−83.91 kW（受电）** | 台区1 的 200 kW 负荷比 140 kW 大，整站没有反向潮流 |

只看到"台区2 外送 140 kW"就说"整站反向潮流"，是错的。

## 顺带一个真实代价

1.6 km 低压线反向送 140 kW，**网损约 23.9 kW（占负荷 8.54%）**。
这不是算错了：0.4 kV 下 140 kW 约 224 A，1.6 km 的 R≈0.158 Ω，
三相损耗 3I²R ≈ 23.8 kW，与结果吻合。长低压线本身就不经济。

## 怎么用

在问答页说：

```
算一下桌面上的配网承载力算例_双台区对比，并给我计算报告
```

或到「算例分析」页选中本目录点「分析」。
报告与页面都会按台区列出每个母线电压，能直接看出"哪个台区有问题"。

## 电压判据

0.90 ~ 1.10 pu —— 这是**本工程规则包 HC-RULES@1.0 的批准值**。
注意它与 GB/T 12325 对 10 kV 的 **±7%** 不是同一口径
（标准更严，工程规则包更宽）。问"是否满足国标"时要把这层差异说清楚。

## 改算例试试

- 把 `PV.dss` 的 `kw=220` 调到 **180** → Vmax 约 1.097，不再越限（临界）
- 调到 **150** → Vmax 约 1.092，更安全
- 把 `Loads.dss` 台区2 负荷调大 → 净外送减小，电压回落

改完在问答页重新问一次即可，会生成新报告。
