# 配网承载力算例 · 全部满足（健康基线）

一条**配置合理**的 10 kV 馈线：负荷与光伏匹配、线路长度正常、配变容量充裕。
**所有约束都满足**，用来做「通过」的对照 —— 让人看到正常的算例长什么样。

## 拓扑

```
变电站 10.5 kV (sourcebus → MVBUS)
  ├ L_MV_1  1.20 km ─ MV_N1
  ├ L_MV_2  1.20 km ─ MV_N2
  └ L_BR_T1 0.25 km ─ [T1 400 kVA] → 低压 0.25 km
                        负荷 150 kW（末端）+ 120 kW（配变侧）
                        光伏 110 kW（末端）
```

主干 LGJ-120｜分支 LGJ-120｜低压 YJV-4×185

## 文件

| 文件 | 内容 |
|---|---|
| `Master.dss` | 建电路 + 求解设置 + 按序 Redirect |
| `LineCodes.dss` | 三种导线型号参数（本例用到 LGJ-120 与 LV_185） |
| `Grid.dss` | 10 kV 主干与台区分支 |
| `Transformers.dss` | T1 400 kVA + 低压线路 |
| `Loads.dss` | 两个负荷点（合计 270 kW） |
| `PV.dss` | 光伏 110 kW |

## 为什么这个算例"全部满足"

三个条件同时成立：

1. **光伏小于本地负荷**（110 < 270 kW）→ 不会有反向潮流；
2. **低压线短**（0.25 km）→ 光伏引起的电压抬升很小，Vmax 才 1.03；
3. **配变容量充裕**（400 kVA 带 270 kW，约 68% 负载率）→ 不过载。

对应地，另两个算例各破坏了其中一条：

| 算例 | 破坏了什么 | 表现 |
|---|---|---|
| 光伏高渗透 | 低压线长 + 负荷远小于光伏 | 电压越上限、设备过载 |
| 双台区对比 | 一台区低压线长 + 光伏大于本地负荷 | 电压越上限（设备未过载） |
| **全部满足** | —— | 全绿 |

## 电压判据

0.90 ~ 1.10 pu —— 本工程规则包 HC-RULES@1.0 的批准值。
本算例 Vmax 1.0290 / Vmin 0.9946，**在任何口径下都满足**
（即使按 GB/T 12325 的 ±7% 也满足），所以它是一个很稳的"健康"基线。

## 改算例试试

把它改成"不健康"很容易，便于对比：

- 把 `PV.dss` 的 `kw=110` 调到 **300** → 光伏超过负荷，出现反向潮流，
  末端电压也会抬高
- 把低压线 `length=0.25` 加到 **1.2** → 末端电压明显下降
- 把 `T1` 的 `kva=400` 改成 **200** → 配变过载

每次改完在问答页重新问一次，会生成新报告，可与原报告对照。
