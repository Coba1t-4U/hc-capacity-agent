# 配网承载力 · 光伏高渗透算例

一个**新建的** OpenDSS 算例，用来演示"配网承载力为什么会被电压上限卡住"。

## 怎么用

打开「配网承载力与主配微协同优化 Agent」，在**问答**页直接说：

```
算一下桌面上的 OpenDSS 算例，并给我计算报告
```

也可以指定路径：

```
分析 C:\Users\Chen\Desktop\配网承载力算例_光伏高渗透
```

系统会真的跑一次潮流，然后在回答里给出结论，并出现一个
**「打开计算报告」** 按钮，点它就能打开 Word 报告。

也可以到「算例分析」页，选中本目录后点「分析」，同样能出报告，还能看
母线电压表、支路负载表和越限明细。

## 算例意图

这是一条**农网长馈线**：主干 4.2 km，末端台区接了大容量光伏，而当地负荷很小。
"大光伏 + 小负荷"会同时暴露两类问题：

1. **电压上限被顶到** —— 光伏把低压末端电压抬过 1.10 pu
2. **反向潮流** —— 光伏出力大于本地负荷，功率倒送上级电网

这正是配网承载力最典型的受限场景：**不是设备不够，而是电压先到限值**。

## 拓扑

```
变电站 10.5 kV (sourcebus → MVBUS)
  ├ L_MV_1  1.40 km ─ MV_N1 ─┬ L_BR_T1 0.30 km ─ T1 200kVA ─ 台区1（负荷 45 kW）
  ├ L_MV_2  1.40 km ─ MV_N2  │
  └ L_MV_3  1.40 km ─ MV_N3 ─┴ L_BR_T2 0.50 km ─ T2 100kVA ─ 台区2（负荷 40 kW + 光伏 220 kW）

主干 LGJ-120（合计 4.2 km）｜分支 LGJ-70｜低压 YJV-4×185（台区2 低压 1.10 km）
```

## 文件说明

| 文件 | 内容 |
|---|---|
| `Master.dss` | 主文件：建电路、求解设置、按顺序 Redirect 其余文件 |
| `LineCodes.dss` | 三种导线型号的 R/X/C 与额定电流 |
| `Grid.dss` | 10 kV 主干、分支、联络线（联络线常开） |
| `Transformers.dss` | 两台配变 + 低压线路 |
| `Loads.dss` | 三个负荷点（合计 85 kW，功率因数 0.90） |
| `PV.dss` | 光伏 220 kW（含**容量为什么取 220** 的标定记录） |

## 预期结果（已跑过，可核对）

| 项目 | 数值 |
|---|---|
| 收敛 | 是，4 次迭代 |
| 母线 / 支路 | 12 / 12 |
| 总负荷 | 85 kW |
| 分布式电源出力 | 220 kW |
| 源侧交换 | +119.26 kW（**正数＝倒送**） |
| 网损 | 15.74 kW（占负荷 18.51%） |
| 最高电压 | **1.13660 pu @ LV_T2_N2**（超 1.10 上限 +0.0366） |
| 最低电压 | 1.00836 pu @ LV_T1_N1 |
| 电压越限母线 | **1 个**：LV_T2_N2（1.1366）<br>（LV_T2_N1 为 1.0820，在 0.90~1.10 内不越限） |
| 设备过载 | T2 变压器 145.6%（100 kVA 带 220 kW 光伏） |

PV 容量的标定过程（同一网架，只改光伏）：

| PV | 最高电压 | 结论 |
|---|---|---|
| 0 kW | 1.02960 | 正常 |
| 100 kW | 1.06191 | 正常，源侧仍受电 |
| 150 kW | 1.09234 | 接近 1.10，仍在内 |
| **200 kW** | 1.12380 | **已越限** |
| **220 kW** | **1.13660** | 本算例取值，明确越限 |
| 300 kW | 1.18472 | 明显越限 |

所以 220 kW 是"略超上限"的取值，用来演示**电压约束先于设备容量被顶到**。

## 重要口径声明

本算例只做**一个稳态断面**的潮流与约束校核，**不产出开放容量**。

开放容量（承载力）需要容量搜索（梯度/二分）、经批准的规则包与独立复算，
那是针对本工程模型格式的流程，不适用于外部原生算例。
所以报告里明确写"本次为原生算例分析，不含容量结论"，问答回答里也会这样说明。

## 改算例试试

想换工况，只改 `PV.dss` 里的 `kw=220` 即可：

- 调到 150 → 不再越限，可以看到"临界但满足"的样子
- 调到 300 → 越限更明显，反向潮流更大
- 把 `Loads.dss` 的负荷调大 → 反向潮流减小，甚至恢复正向

改完在问答页重新说一遍"算一下桌面上的算例"即可，会生成新报告。
