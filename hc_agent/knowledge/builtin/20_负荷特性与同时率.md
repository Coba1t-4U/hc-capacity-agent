# 负荷特性与同时率

承载力最后要落到"能接多少 kW"。而这个 kW 是**什么口径**——
装机、最大负荷、同时最大、年最大——直接决定结论差多少。
本章把口径与常用系数讲清楚。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、四个必须分清的口径

| 口径 | 含义 | 用在哪 |
|---|---|---|
| **装机容量** | 设备铭牌容量之和 | 设备选型、报装 |
| **最大负荷** | 某用户/某台区自身出现的最大功率 | 单点校核 |
| **同时最大负荷** | 多个用户**同时**出现的最大功率 | 台区/馈线校核 |
| **年最大负荷** | 一年中出现一次的最大值 | 规划、容载比 |

**"各用户最大负荷之和"一定大于等于"同时最大负荷"**，
因为各用户的最大值通常不在同一时刻出现。这个差额就是同时率。

## 二、同时率与需要系数

### 同时率（coincidence factor）

```
同时率 K_同 = 区域同时最大负荷 / 各用户最大负荷之和        （≤ 1）
```

- 用户越多、负荷越分散，同时率越低；
- 居民负荷的同时率通常明显低于工业负荷；
- 台区级常见 0.6 ~ 0.9【待核】，馈线级更低。

### 需要系数（demand factor）

```
需要系数 K_需 = 用户最大负荷 / 用户设备装机容量            （≤ 1）
```

需要系数法计算负荷：

```
P_js = K_需 × ΣP_装机
```

常见需要系数【待核，出自 GB/T 50293《城市电力规划规范》与各类负荷计算手册】：

| 负荷类型 | 需要系数范围 |
|---|---|
| 住宅（集中电表） | 0.4 ~ 0.6 |
| 商业 | 0.6 ~ 0.8 |
| 工业 | 0.5 ~ 0.8（视行业差异极大） |
| 农业灌溉 | 0.3 ~ 0.6 |

**这两个系数不能混用**：需要系数是"装机 → 单用户最大"，同时率是"单个最大 → 群体最大"。

## 三、负荷率与峰谷差

```
负荷率 = 平均负荷 / 最大负荷
峰谷差率 = (最大负荷 − 最小负荷) / 最大负荷
```

负荷率越高，设备利用越充分；峰谷差越大，调峰压力越大，
**储能与需求响应的价值也越大**。

分布式光伏的特点是"出力与负荷反相"：
白天光伏出力高峰，居民负荷低谷 → **中午容易反向潮流、晚上光伏为零却要顶峰**。
所以承载力评估必须做**多场景、分时段**校核（本工程 `scenario_count`、`slice_count` 就是为此）。

## 四、本工程怎么用这两个系数（重点）

`HC-RULES@1.0` 批准的两个参数：

| 参数 | 取值 | 作用 |
|---|---|---|
| `coincidence`（同时率） | **0.9** | 物理可开放容量 → 管理可开放容量 |
| `margin`（裕度） | **0.1** | 再打 10% 折扣留安全余量 |

计算式：

```
管理可开放容量 = 物理可开放容量 × 同时率 × (1 − 裕度)
               = 物理 × 0.9 × 0.9
               = 物理 × 0.81
```

**用 FD002 验算**：

```
物理 333.984375 kW × 0.81 = 270.52734375 kW
```

与产物里的 `capacity_managed_kw` 逐位一致。

### 为什么是 0.9 与 0.1（而不是别的数）

这两个是**项目批准值**，不是标准规定。
它们的含义是：

- 同时率 0.9：承认"所有接入点不会同时满发"这一现实（乐观口径）；
- 裕度 0.1：为预测误差、测量误差、运行方式变化留余量。

**换一组数结论就变**：若同时率取 0.8、裕度取 0.15，则系数变 0.68，
管理容量会降到约 227 kW。所以回答时**必须报出用的是哪组系数**。

## 五、负荷预测的常用方法

| 方法 | 适用 | 局限 |
|---|---|---|
| 弹性系数法 | 有历史电量与 GDP 数据 | 依赖宏观经济假设 |
| 年均增长率法 | 短期、稳定增长区 | 忽略结构性变化 |
| 回归分析 | 有较长历史序列 | 拐点识别差 |
| 灰色模型 GM(1,1) | 小样本 | 只适合近似指数增长 |
| 人均用电量法 | 新区规划 | 需要同类地区对标 |

【待核】各类方法的适用边界是经验总结，具体选用要结合数据可得性。

**一个硬要求**：负荷预测结果进入承载力评估时，必须标明是**哪种口径**
（最大负荷 / 同时最大 / 年平均），否则和"可开放容量"放在一起比较就是错的。

## 六、常见误区

1. **拿"装机容量"直接减"可开放容量"**：口径不同，一个含需要系数一个不含。
2. **把同时率当成"必降系数"**：它取决于用户构成，用户单一（如一个大工业）时接近 1。
3. **忽略光伏与负荷的时序错配**：只看峰值时刻，会漏掉光伏零出力时的重载工况。
4. **把年度最大负荷当成某一时刻的负荷**：年最大值只出现一次，用它算潮流会偏严。
5. **裕度与同时率混用**：一个是"不同时出现"，一个是"留安全余量"，物理含义不同。
