# 分布式电源接入的系统影响

"承载力"这个问题的物理来源就是本章：分布式电源接进来会改变配网的
电压分布、潮流方向、保护配合与电能质量。这些影响逐条决定了约束怎么设。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、电压抬升（最常见的限制因素）

光伏/风电在**末端**接入时，功率要反向流经线路，线路阻抗上的压降变成"压升"：

```
ΔU ≈ (P·R + Q·X) / U_n          （P 为注入功率，方向与受电相反）
```

三个放大因素：

| 因素 | 为什么放大 |
|---|---|
| 接入点越靠近末端 | 反向功率流经的线路越长、R 越大 |
| 低压线越长 | 0.4 kV 下 R 相对更大（截面小、电流大） |
| 电源功率因数越接近 1 | 没有无功吸收来抵消压升 |

**这就是本工程两个算例的核心差异**：

| 算例 | 低压线长度 | 光伏 | 最高电压 | 结论 |
|---|---|---|---|---|
| 配网承载力算例_全部满足 | 0.25 km | 110 kW | 1.0290 pu | 不越限 |
| 配网承载力算例_双台区对比 | 台区2 1.6 km | 220 kW | 1.1317 pu | **越 1.10 上限** |
| 配网承载力算例_光伏高渗透 | 1.6 km | 220 kW | 1.1366 pu | 越限 + 配变过载 |

同样是 220 kW，低压线从 0.25 km 变到 1.6 km，结果完全不同。

### 抑制电压抬升的手段

1. **逆变器吸收无功**（Q 控制）—— 最经济，但受功率因数范围限制（常见 0.95 超前~滞后）；
2. **缩短低压供电半径**（规划手段）—— 最根本；
3. **调压器/有载调压配变** —— 需要设备；
4. **储能** —— 中午充电、晚上放电，兼具削峰；
5. **限制接入容量** —— 就是承载力评估给出的结论。

## 二、反向潮流（本工程的显式约束）

当分布式电源出力超过本地负荷 + 网损时，功率向变电站**倒送**：

```
倒送条件：P_DG > P_load + P_loss
```

影响：

- **网损先降后升**：DG 出力从 0 增加时网损下降（就近供电），
  超过本地负荷后网损又上升（长距离倒送）。**存在一个最优渗透率**；
- 上级电网的调压、保护、计量要能适应双向潮流；
- 部分地区的并网规定对倒送功率有明确限值。

本工程 `REVERSE_FLOW_LIMIT` 取 **≤ 400 kW**（**项目批准值**，不是全国统一数）。

**用算例看"两层净功率"**（`双台区对比`）：

| 口径 | 数值 | 说明 |
|---|---|---|
| 台区2 内部 | 220 − 80 = 约 140 kW 净外送 | 穿过 T2 与 1.6 km 低压线 |
| 整条馈线 | 源侧 −83.91 kW（**受电**） | 台区1 的 200 kW 负荷更大 |

只看到"台区2 外送 140 kW"就说"整站倒送"，是错的。

## 三、网损的变化规律

```
网损 ≈ Σ (P_flow² + Q_flow²) / U² · R
```

- DG 出力小时：就近供电，线路潮流减小 → **网损下降**；
- DG 出力超过本地负荷：功率反向长距离输送 → **网损上升**；
- 所以"装得越多越省线损"是错的，**存在最优渗透率**。

本工程 `双台区对比` 的 23.91 kW 网损（占负荷 8.54%）就是长低压线反向送电的代价。

## 四、短路电流增大

见《短路电流与设备校验》。要点：

- 逆变器型电源的短路贡献受变流器限流，约为额定的 1.1~1.5 倍【待核】；
- 但多点接入叠加后仍会抬升，可能超过开关设备开断能力；
- 本工程 `SHORT_CIRCUIT_LIMIT` ≤ 20 kA（项目批准值）。

## 五、保护配合与孤岛

| 问题 | 机理 | 后果 |
|---|---|---|
| **过流保护灵敏度下降** | DG 分担了故障电流，流过保护的电流变小 | 保护可能拒动 |
| **保护范围变化** | 双向潮流使原整定不再匹配 | 可能误动/越级 |
| **反孤岛** | 电网停电但 DG 仍在供电 | 危及检修人员安全 |
| **自动重合闸配合** | 重合闸时 DG 未解列 | 非同期合闸冲击 |

**规范要求**：分布式电源必须具备**孤岛检测与解列**能力（GB/T 33593、Q/GDW 1484）。
本工程**不做保护整定计算**（`caliber.unsupported` 已列明"保护配合"未覆盖），
所以问"保护会不会误动"时要回答"本版未做保护校验"。

## 六、谐波与电能质量

- 光伏/储能的逆变器是**电力电子设备**，会产生谐波；
- 并网标准要求并网点谐波电流与电压畸变率满足 **GB/T 14549**；
- 多台逆变器并联时谐波可能**叠加放大**（谐振）；
- 电压波动与闪变按 **GB/T 12326** 校验。

本工程**不做谐波与闪变校核**（未覆盖），
引用注意事项：不要拿"THD 满足国标"去反推"承载力还有余量"。

## 七、三相不平衡

分布式电源常以**单相**形式接入低压（户用光伏），会加剧三相不平衡。
本工程判据 `IMBALANCE_LIMIT` ≤ **2.0%**，与 GB/T 15543 的公共连接点口径一致。

注意区分：

- **公共连接点** 2%（短时 4%）—— 本工程用的口径
- **每个用户引起** 1.3%（短时 2.6%）—— 差一倍多

## 八、把这些影响映射到"承载力约束"

| 物理影响 | 对应的承载力约束 | 本工程判据 |
|---|---|---|
| 电压抬升 | 电压上限 | 0.90 ~ 1.10 pu |
| 反向潮流 | 反向潮流限值 | ≤ 400 kW |
| 网损上升 | 不作为硬约束（作为经济性指标） | 报告中给出 |
| 短路电流增大 | 短路电流限值 | ≤ 20 kA |
| 单相接入 | 三相不平衡 | ≤ 2.0% |
| 设备过载 | 载流/容量 | 负载率 ≤ 100% |
| 保护/谐波/暂态 | **未覆盖** | `caliber.unsupported` 列明 |

**这张表是回答"为什么某个约束先到限"的底层依据。**

## 九、一个反直觉结论

**设备没满，电压先满。**

`双台区对比` 算例里最大负载率只有 79.18%（没有过载），
但台区2 末端电压已经到了 1.1317 pu，超上限 0.0317 pu。

所以"配变还有余量"不等于"还能再接光伏"。承载力评估之所以必要，
就是因为它算的是**电气约束**，不是铭牌容量。
