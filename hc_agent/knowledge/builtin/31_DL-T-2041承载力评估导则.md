# DL/T 2041 承载力评估导则

《分布式电源接入电力系统承载力评估导则》——**配电网承载力评估唯一的直接行业标准**。
本工程的口径体系应以它为主干，其他标准（GB/T 12325 等）用来补充具体限值。

> **版本提示（重要）**
> | 版本 | 状态 |
> |---|---|
> | DL/T 2041-2019 | 已被替代 |
> | **DL/T 2041-2025** | 国家能源局 2025 年第 7 号公告发布（2025-12-18），**2026-06-18 起实施** |
>
> 本工程编制日期在 2026-10，处于**新旧交替期**。引用时必须先问清按哪个版本。

## 一、两个层级的承载力（2025 版的核心调整）

2019 版只有笼统的"承载力"。**2025 版明确分成两级**：

### 系统级承载力

> 某一行政区或电力调度独立控制区域内可接入分布式电源的**最大装机容量**。

- **计算方法**：时序生产模拟仿真，得到**承载力区间**
- 计算范围：省级行政区 / 电力调度独立控制区域
- 结果**分解**到区域内各县级行政区

**关键点**：系统级看的是"电量与调峰"层面，不是潮流约束。
所以它需要**时序生产模拟**（8760 小时级别的电量平衡），
与配网的潮流校核是两套方法。

### 设备级承载力

> 220(330) kV 及以下**变（配）电设备供电范围内**可接入分布式电源的最大装机容量。

- **计算方法**：在**变压器反向负载率不越限**条件下，算承载力区间
- 对象：各电压等级变压器（220/330、110/66、35、10 kV）
- 周期：宜按**季度**

**关键点**：设备级的核心约束被明确写为**反向负载率不越限**。
这与本工程的 `REVERSE_FLOW_LIMIT` 直接对应。

### 两个层级的区别（最容易混淆的地方）

| | 系统级 | 设备级 |
|---|---|---|
| 对象 | 行政区 / 调度区 | 变压器供电范围 |
| 方法 | 时序生产模拟 | 潮流 + 反向负载率校核 |
| 周期 | 年度 | 季度 |
| 回答的问题 | 全省还能装多少 | 这个台区/变电站还能接多少 |
| 本工程覆盖 | **不覆盖** | **覆盖** |

**本工程做的是设备级**（潮流 + 约束 + 容量搜索）。
被问到"全省/全县还能装多少"时，必须说清那属于系统级，本工具不做。

## 二、可开放容量评估（逐级分解）

2025 版规定按**下级服从上级**原则逐级开展：

```
县级行政区
  └ 220(330) kV 变压器
      └ 110(66) kV 变压器
          └ 35 kV 变压器
              └ 10 kV 变压器
```

统计口径：各层级供电范围内**已备案 + 已并网**的分布式电源装机，
按承载力校核结果确定可开放容量。

**这条对本工程的做法有直接约束**：
在一个 10 kV 馈线上算出的可开放容量，**不能超过上级变压器分配到它的份额**。
本工程当前的容量搜索没有做这个"上级约束"，这是一个已知缺口（见第八节）。

## 三、红黄绿分级（2025 版的重大变化）

### 2019 版：80% 硬门槛

2019 版以"分布式电源装机 / 承载力 = 80%"作为分档线，简单但粗糙 ——
大量地区因为一个数字被判为"红区"，限制接入。

### 2025 版：**不再以 80% 为硬性指标**

改按**可开放容量区间**判定等级。原文要点：
- 等级根据"分布式电源可开放容量区间"逐级评估；
- 并要求"因地制宜提出承载力提升措施"。

> **诚实说明**：2025 版具体的分档阈值以标准正文为准。
> 本知识库没有拿到正式文本的表格，只确认了"取消 80% 硬指标、改按可开放容量区间"这一原则性变化。
> **引用具体档位数值前必须查正式文本。**
> 媒体标题所谓"许多红区变绿"就是这个变化的直观结果。

### 与本工程红黄绿的关系

本工程当前用**项目批准值**（见《红黄绿分级》）：
- 红：可开放容量 ≤ 0 kW
- 黄：≤ 15%（相对物理容量）
- 绿：> 15%

这是**项目自定口径**，不是 DL/T 2041 的规定。
被问"分级依据是什么"时，必须说清是本项目批准值。

## 四、典型时刻的选取（2025 版明确）

设备级承载力计算**宜**在以下时刻选取：

> 当年度**春季或秋季的工作日午间**，选取分布式电源**出力最大**的典型时刻，
> 并预测用电负荷、电源出力、新型电力储能装机等相关参数。

**为什么是春秋季午间**：
- 春秋季光伏辐照好、温度不高（组件效率高）；
- 午间负荷通常低谷 → **反向潮流最严重**；
- 工作日而不是周末（负荷曲线更有代表性）。

这条印证了本工程《新能源出力特性与场景构建》里
"高光伏 + 低负荷"场景的设计思路 —— **DEL/T 2041 直接指定了这类场景**。

## 五、承载力提升措施

2025 版明确要求"因地制宜提出承载力提升措施"。
这与本工程上一轮做的**整改建议候选**（SK-13）方向一致。

常见措施（按本工程候选库编号）：
- `RM-V-01` 缩短低压半径 / 加粗截面
- `RM-V-02` 调分接头
- `RM-V-03` 逆变器无功
- `RM-C-01` 配储能
- `RM-T-02` 配变增容 / 分流

## 六、与本工程现有能力的对照

| DL/T 2041 要求 | 本工程 | 说明 |
|---|---|---|
| 设备级承载力（潮流 + 反向负载率） | ✅ 完整 | SK-04~SK-10 |
| 五类约束校核 | ✅ 超出标准要求 | 标准只明确反向负载率；本工程另做电压/载流/不平衡/短路 |
| 逐级可开放容量（下级服从上级） | ⚠️ **未做** | 只算单层，不含上级份额约束 |
| 系统级承载力（时序生产模拟） | ❌ **未做** | 需要 8760 电量平衡，不在本工具范围 |
| 春秋季午间典型时刻 | ✅ 等价 | 通过场景集实现，但未强制"春秋工作日午间" |
| 承载力提升措施 | ✅ 已做 | SK-13 整改候选 |
| 红黄绿分级 | ⚠️ 口径不同 | 本工程用项目批准值，非标准档位 |

## 七、按季节/时刻取数的工程做法

| 参数 | 做法 | 依据 |
|---|---|---|
| 时段 | 春秋季工作日 11:00–14:00 | 2025 版明确 |
| 光伏出力 | 取该时段最大出力 | 同上 |
| 负荷 | 同期实测预测，不是年最大值 | 同上 |
| 储能 | 计入当时的充放电计划 | 同上 |
| 校核周期 | 季度 | 同上 |

**常见错误**：拿年度最大负荷 × 年度最大光伏出力去组合 ——
这两个极值几乎不会同时出现，算出来会严重偏保守。

## 八、本工程的已知缺口（如实列出）

1. **没有做逐级约束**：10 kV 层的可开放容量没有受上级变压器份额限制。
   现实中上级已经满载时，下级算出的"还能接 300 kW"是不能兑现的。
2. **没有做系统级评估**：县域/省域的可接入总量需要时序生产模拟，本版不做。
3. **红黄绿档位与新版标准不一致**：本工程用项目批准值，新版改按可开放容量区间。
4. **典型时刻未强制校验**：场景集是用户/规则包配置的，
   没有硬性保证包含"春秋工作日午间最大出力"这一时刻。

**回答"这个数能不能对外发布"时**，如果对方要的是 DL/T 2041 口径的可开放容量，
必须先补上第 1 条（逐级约束），否则只能作为**单层设备级评估结果**使用。
