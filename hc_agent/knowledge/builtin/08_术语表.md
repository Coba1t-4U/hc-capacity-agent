# 术语表

| 术语 | 英文 / 字段 | 含义 |
|---|---|---|
| 承载力 | hosting capacity | 不违反约束前提下可额外接纳的分布式电源容量 |
| 开放容量 | open capacity | 与承载力同义 |
| 物理可开放容量 | capacity_physical_kw | 只受物理约束限制的最大可接入量 |
| 管理可开放容量 | capacity_managed_kw | 物理值叠加管理系数与裕度后的可发布值 |
| 主导限制因素 | binding_constraint | 把容量卡住的那一类约束 |
| 卡点详情 | binding_detail | 具体卡在哪个对象、哪个指标、实测值、限值、余量 |
| 可行下界 | feasible_lower_kw | 搜索中仍满足全部约束的最大试探值 |
| 不可行上界 | infeasible_upper_kw | 搜索中已违反约束的最小试探值 |
| 时间片 | slice / timestamp | 一个潮流计算断面对应的时刻 |
| 场景 | scenario | 一组时间片 + 工况定义 |
| 同时率 | coincidence_factor | 管理口径参数，本规则包 0.9 |
| 裕度比例 | margin_ratio | 管理口径参数，本规则包 0.1 |
| 余量 | margin | 实测值到限值的距离，负值表示已越限 |
| 越限 | violation / fail | 实测值超出限值 |
| 未覆盖 | unknown | 能力未覆盖或数据缺失，算不出来 |
| 独立复算 | independent verification | 换通道重跑并逐字段比对 |
| 发布门禁 | release gate | 复算 + 专业复核 + 审批 三道关卡 |
| 灰色等级 | grey | 内部态，存在数据风险或未覆盖项，不对外发布 |
| 反向潮流 | reverse flow | 分布式电源出力倒送上级电网 |
| 渗透率 | penetration | 分布式电源容量相对负荷的比例 |
| 标幺值 | pu (per unit) | 相对基准值的比值，电压常用 |
| 主配微协同 | main-grid / distribution / microgrid coordination | 主网、配网、微网三层协同优化 |

## 字段名对照（读产物时用）

- 电压：`voltage_pu`，单位 pu
- 负载率：`loading_pct`，单位 %
- 不平衡度：`imbalance_pct`，单位 %
- 反向潮流：`reverse_flow_kw`，单位 kW
- 短路电流：`fault_current_a`，单位 A
- 容量：`*_kw`，单位 kW
