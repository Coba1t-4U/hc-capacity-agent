# 事故、应急与供电可靠性

承载力评估都默认"网络正常"。但用户常问
"故障时怎么办、还能不能转供、可靠性够不够"。本章把这一层讲清楚。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、本工程明确不做的事（先说清楚）

`caliber.unsupported` 已列明：

- **N-1 自动扫描** —— 未覆盖
- **暂态稳定、保护配合** —— 未覆盖
- 现场控制闭环 —— Agent 无任何设备写操作能力

**所以问"N-1 下能接多少"时，正确回答是**：
本版只做正常运行方式（含给定场景）的约束校核，
不自动枚举故障方式，给不出"N-1 后"的承载力。

## 二、可靠性常用指标

| 指标 | 全称 | 含义 |
|---|---|---|
| **SAIDI** | 系统平均停电时间 | 户均年停电小时数 |
| **SAIFI** | 系统平均停电频率 | 户均年停电次数 |
| **CAIDI** | 用户平均停电持续时间 | SAIDI / SAIFI |
| **ASAI** | 供电可用率 | 1 − SAIDI / 8760 |
| **EENS** | 电量不足期望 | 年缺供电量 kWh |

本工程**不算这些指标**（需要全年故障率与修复时间数据）。
但可以用它们向用户解释"可靠性是怎么考核的"。

## 三、N-1 与转供

### N-1 准则

任一元件（线路、变压器）故障退出，不影响对用户供电（或只影响允许范围）。

配网里常说的 N-1 主要看：

| 元件 | N-1 后要满足 |
|---|---|
| 一条 10 kV 线路 | 通过联络开关转供到相邻线路 |
| 一台配变 | 通过低压联络转带（若有） |
| 一段主干 | 分段开关隔离 + 转供 |

### 转供的约束（这点常被忽略，但和承载力直接相关）

```
转供成功的条件：相邻线路的剩余容量 ≥ 被转供负荷
```

**这正是承载力评估与规划的交汇点**：
如果每条线路都"满载运行"，就没有转供能力；
留一定裕度（即"可开放容量"不要用满）才能保证 N-1 后的转供。

**所以可开放容量用完，不只是"不能再接光伏"，也是"没有转供能力了"。**

### 联络率

```
联络率 = 有联络开关的线路数 / 线路总数
```

城市配网普遍要求较高联络率，但"有联络"≠"能转供"——
还要看容量匹配与电压合格。

## 四、分布式电源带来的新问题

| 问题 | 机理 | 后果 |
|---|---|---|
| **反孤岛失败** | 电网停电，DG 未解列 | 形成孤岛，危及检修人员 |
| **重合闸不同期** | 重合时 DG 仍在发电 | 非同期冲击，可能损坏设备 |
| **转供时保护失配** | 转供后潮流方向变了 | 保护误动/拒动 |
| **转供后电压越限** | 转供线路本来就接近满载 | 转供后越限更严重 |

**规范要求**：分布式电源必须具备孤岛检测与快速解列能力
（GB/T 33593、GB/T 19964）。

**回答"故障时光伏会不会继续供电"时**：
正常设计的并网逆变器会在电网失电后**快速跳闸**（孤岛保护），
不会向停电线路供电 —— 但这是**设备能力**，
本工程不做保护与孤岛的仿真验证。

## 五、应急场景下的承载力变化

| 情形 | 对承载力的影响 |
|---|---|
| 一台配变故障 | 该台区负荷转移到低压联络 → 剩余台区载流压力上升 |
| 一条线路故障 | 转供后相邻线路负载率上升，可能过载 |
| 上级变电站主变检修 | 全站供电能力下降 |
| 恶劣天气（高温） | 载流量按温度修正**下降** → 承载力下降 |
| 覆冰/大风 | 线路载流与机械强度受限 |

**"高温降容"是个实用细节**：
导线载流量按环境温度修正，常见修正系数【待核】：

| 环境温度 | 相对载流量 |
|---|---|
| 25 ℃ | 1.00（基准） |
| 35 ℃ | 约 0.92 |
| 40 ℃ | 约 0.88 |

所以**同一条线路，夏天能带的负荷比春秋少**。
承载力结论如果不注明环境温度，是有歧义的。

## 六、可靠性 vs 经济性 vs 承载力

三者的关系：

```
可靠性要求 → 需要备用容量 → 限制可开放容量（不能接满）
经济性要求 → 希望设备利用率高 → 希望少留备用
承载力    → 给出"电气极限"，是上限而非目标
```

**工程上的做法**：承载力 × 同时率 × (1−裕度) 得到"管理可开放容量"，
其中裕度就是给预测误差与运行方式变化留的空间。
本工程取 `0.9 × 0.9 = 0.81`（见《负荷特性与同时率》）。

严格说，**裕度里也隐含了一部分"应急与不确定性"的考虑**，
但它不是严格的 N-1 校核结果。

## 七、常见误区

1. **把"可开放容量为 0"理解成"这条线不能用了"**。
   它说的是"按当前约束不能再新增分布式电源"，不是"不能供电"。
2. **以为留了裕度就等于做了 N-1**。裕度是粗放的空间，
   N-1 需要逐个元件枚举校验。
3. **只看正常运行方式就下结论**。转供后、检修时都可能出问题。
4. **忽略温度修正**。夏天实际能带的负荷比额定小。
5. **以为光伏能当应急电源**。并网逆变器在失电时会解列，不能当 UPS。

## 八、怎么核实

- DL/T 836《供电系统用户供电可靠性评价规程》—— 可靠性指标定义
- GB/T 33593 / GB/T 19964 —— 孤岛保护与并网要求
- DL/T 5222 —— 载流量与温度修正
- 国网《配电网技术导则》—— N-1、联络率、转供要求
