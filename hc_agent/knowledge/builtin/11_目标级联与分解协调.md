# 目标级联法与分解协调方法

## 目标级联法（ATC, Analytical Target Cascading）

ATC 的核心思路：**把一个大问题拆成上下两层，各自优化，
再用罚函数逼两边对同一个耦合变量取相同的值**。

### 一次迭代的流程

1. 上层把自己希望的交换功率（目标值）**下发**给下层；
2. 下层在自己约束下优化，**回报**它实际能接受的交换功率；
3. 上层比较"目标"与"实际回报"的**不一致量（误差）**；
4. 误差超阈值就**加大罚函数权重**，回到第 1 步。

### 收敛判据与参数（配套算例的真实取值）

本项目配套的三微网算例（`mainATC2.m` / `parameterATC.m`）里：

| 参数 | 取值 | 含义 |
|---|---|---|
| 一致性误差阈值 | `postError > 0.2` 继续迭代 | 上下层耦合变量不一致量小于 0.2 视为收敛 |
| 最大迭代 | `kloop = 28` | 外层迭代上限 |
| 罚函数系数更新 | `beta = 2.3`、`gama = 0.3` | 误差不降时放大罚权重 |
| 初始乘子 | `v = 0.1`、`w = 0.1`（3×24） | 每个微网每个时刻一个初值 |
| 时段数 | `Horizon = 24` | 24 小时 |
| 场景数 | `n_s` | 分布鲁棒的多场景维度 |
| 储能退化费用 | `rou_ESS = 18` | 元/kWh 级 |
| 燃料/发电费用 | `rou_fuel = 400`、`rou_fuel_G = 600` | 元/MWh 级 |
| 启停费用 | `rouG_ON = 0.1`、`rouG_OFF = 0.05` | 千元级 |

罚函数权重按时段不同（`pho` 是一个 1×24 的向量），
说明不同时段的耦合强度不同 —— 高峰时段需要更大的罚权重才能拉平。

### 为什么用罚函数而不是直接消元

因为上下层的信息不共享：上层不知道下层全部约束，下层也不知道上层全部约束。
罚函数法只要求交换**耦合变量的目标值与回报值**，属于"最小数据交换"。

## 其他常用分解方法

| 方法 | 思路 | 适用 |
|---|---|---|
| GBD（广义 Benders 分解） | 主问题给协调量，子问题回传割平面 | 两阶段、混合整数 |
| 最优性条件分解（OCD） | 复制耦合变量，用 KKT 条件的拉格朗日乘子协调 | 连续凸问题 |
| 多参数规划 | 预先求"参数→最优解"的分段映射 | 需要反复求解同结构问题 |
| ADMM | 增广拉格朗日 + 交替方向 | 可并行、收敛条件清楚 |
| ATC（目标级联） | 分层罚函数 | 多层、层级结构清晰 |

这些方法在本领域文献里都被用于主配（输配）协同调度，
选择依据主要是**层级结构是否清晰**、**能否并行**、**是否需要整数变量**。

## 收敛性与工程注意事项

1. **可能不收敛**：ATC 罚函数法在非凸问题上没有全局收敛保证，
   必须设最大迭代（本项目 28 次）并在达不到阈值时**如实报"未收敛"**。
2. **初值敏感**：初始乘子取 0.1 是经验值，初值不当会震荡。
3. **误差定义要一致**：上下层算"不一致量"的公式必须同一个，
   否则会出现"上层认为收敛、下层还在动"的假收敛。
4. **不能只看迭代次数**：迭代到上限不等于收敛。

## 与承载力的连接

在分解协调框架下算可开放容量，要注意：

- 容量是**耦合变量的可行范围**，它依赖上层给的目标值；
- 上层目标一变，下层报的容量就变；
- 所以协同口径的容量必须写明"在什么协调目标下"，
  不能给一个不带前提的数字。
