# 经济性与投资评估

承载力给的是**能接多少**（技术可行）。但"该不该接、值不值得改造"
是经济性问题，两者不能混。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述（含价格类数据，时效性强，务必用当期数据）。

## 一、先分清两个问题

| 问题 | 谁回答 | 输出 |
|---|---|---|
| **能不能接**（技术可行） | 承载力评估 | kW 数字 + 越限约束 |
| **接了划不划算** | 经济性评估 | 收益率/回收期/度电成本 |

**技术可行的容量，不代表经济上值得投；反过来也一样。**
承载力报告里不该混入电价与投资假设，否则结论会变味。

## 二、常用的经济性指标

| 指标 | 含义 | 判据 |
|---|---|---|
| **静态投资回收期** | 累计净收益 = 投资额所需的年数 | 越短越好，常看是否 < 8~10 年 |
| **净现值 NPV** | 全部现金流折现之和 | NPV > 0 才值得投 |
| **内部收益率 IRR** | 使 NPV=0 的折现率 | IRR > 基准收益率（如 8%） |
| **平准化度电成本 LCOE** | 全生命周期成本 / 总发电量 | 越低越好，用于对比不同技术 |
| **线损率** | 网损 / 供电量 | 越低越好，反映网络效率 |

【待核】折扣率、基准收益率的取值随项目与政策变化，不写死。

## 三、分布式光伏的收益怎么算

简化模型（不考虑补贴与绿证）：

```
年收益 = 年发电量 × 自用比例 × 用电电价
       + 年发电量 × (1−自用比例) × 上网电价
       − 年运维成本
```

关键变量：

| 变量 | 典型取值 | 影响 |
|---|---|---|
| 年利用小时数 | 1000 ~ 1300 h（资源较好地区）【待核】 | 决定发电量 |
| 系统效率（PR） | 0.75 ~ 0.85【待核】 | 直接乘在发电量上 |
| 自用比例 | 看负荷曲线，**越高越划算** | 自用电价 > 上网电价 |
| 组件衰减 | 首年 2%，之后每年 0.5%【待核】 | 影响长期收益 |

**自用比例是分布式光伏经济性的核心**：
同样 220 kW，全部自用和全部上网，收益差一倍以上。
这也解释了为什么"光伏配在负荷大的台区更划算"。

## 四、线损的经济价值

线损降低的价值常被低估。用本工程算例算一遍：

| 算例 | 网损 | 占负荷 |
|---|---|---|
| `全部满足` | 2.20 kW | 0.81% |
| `双台区对比` | 23.91 kW | 8.54% |

`双台区对比` 的 23.91 kW 是 1.6 km 低压线反向送 140 kW 的代价。

假设一年有效运行 3000 h、电价 0.6 元/kWh：

```
年线损电量 ≈ 23.91 × 3000 ≈ 71,730 kWh
年线损电费 ≈ 71,730 × 0.6 ≈ 4.3 万元
```

**对比**：把这条低压线从 1.6 km 缩到 0.3 km 的改造投资，
往往几年就能从线损里省回来 —— 这是"缩短供电半径"的经济依据。

## 五、提升承载力的改造手段经济性排序

从便宜到贵（一般规律，具体项目需测算）：

| 手段 | 单位成本量级 | 提升承载力效果 | 备注 |
|---|---|---|---|
| 调整运行方式（分流、改接线） | 极低 | 有限 | 优先做 |
| 配变更换/增容 | 中 | 只解载流 | 不解决电压 |
| 低压线加粗/缩短 | 中高 | **显著**（直击 R） | 最优解常常是它 |
| 加装 SVG/调压器 | 高 | 中等 | 治标 |
| 配储能 | 高 | 视配置 | 需算能量缺口 |
| 新建馈线/切改 | 很高 | 显著 | 规划级方案 |

**"先查运行方式，再考虑改造"** 是工程上的常识 ——
很多"承载力不足"其实是某个开关没合、某个台区没分流。

## 六、度电成本 LCOE 怎么比

```
LCOE = (初始投资 + Σ(年运维/ (1+r)^t)) / Σ(年发电量 × (1−衰减) / (1+r)^t)
```

用途：让**不同技术、不同规模**能横向比。
比如"光伏 + 储能"与"纯光伏"哪个 LCOE 更低，
或者"增加 100 kW 光伏"与"改造低压线"哪个更值。

**注意**：LCOE 只算成本不算收益，
所以"LCOE 低"不代表"值得投"——还要看电价与消纳。

## 七、本工程为什么不做经济性

`caliber.unsupported` 里没有明确列经济性，但本工程的定位是**技术约束评估**：

| 项目 | 本工程 |
|---|---|
| 输入 | 拓扑、负荷、电源、约束、规则包 |
| 输出 | 可开放容量（kW）、越限明细、验证结果 |
| **不含** | 电价、投资额、收益率、回收期 |

理由：

1. **电价与政策变化快**，写进技术报告会让结论过期；
2. 经济性依赖投资估算，而评估工具拿不到准确的工程概算；
3. 混在一起会让"技术可行"被误读成"经济可行"。

**所以问"接这个划算吗"时，正确回答是**：
本工程只做技术可行性（能接多少 kW），经济性需要另做投资分析，
并给出上面几个指标该怎么算。

## 八、绿证与碳收益（简述）

| 机制 | 说明 |
|---|---|
| **绿证（GEC）** | 可再生能源电力消费凭证，可交易 |
| **CCER** | 国家核证自愿减排量 |
| **绿电交易** | 直接购买绿电并获凭证 |

这些会改变收益，但**规则变动频繁**，且与本工程的碳强度估算（见《碳强度与可开放容量》）
是两个不同的东西：

- 碳强度估算：算的是"这个断面每度电排多少碳"（物理量）；
- 碳收益：算的是"能卖多少钱"（经济量）。

## 九、常见误区

1. **把承载力数字直接当投资依据**。承载力争的是技术极限，不是经济最优。
2. **忽略自用比例**。分布式光伏的经济性主要靠自用。
3. **只看初投资不看全周期**。LCOE 与运维成本要一起看。
4. **用过期电价**。电价与补贴政策调整频繁。
5. **忽略线损价值**。长低压线的线损是真金白银。
6. **把碳强度与碳收益搞混**。一个是物理量，一个是钱。

## 十、怎么核实

- 当期电价文件：各省发改委/能源局发布的目录电价与市场化交易价格
- 绿证与 CCER：中国绿色电力证书认购交易平台、全国碳排放权交易市场
- 投资估算：行业定额（如电力建设工程预算定额）
- 光伏系统效率与利用小时：当地气象数据 + 设备样本
