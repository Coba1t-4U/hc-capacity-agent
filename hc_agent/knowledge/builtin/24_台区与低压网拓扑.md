# 台区与低压网拓扑

配网承载力最终落到**台区**这一层。台区是什么、怎么接、
不同接法的电气特性差在哪，直接决定电压与不平衡怎么算。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、什么是台区

**台区**（配电台区）= 一台（或一组）配电变压器 + 其供电范围内的低压网络 + 用户。

```
10 kV 馈线
   └─ 分支线 ── 跌落熔断器/开关 ── 配电变压器（10/0.4 kV）
                                    └─ 低压配电箱
                                        ├─ 主干（三相四线）
                                        ├─ 分支
                                        └─ 接户线 → 用户
```

台区是**低压侧管理与考核的基本单元**，也是承载力评估里"低压约束"的载体。

## 二、常见接线方式

### 10 kV 部分

| 方式 | 特点 | 应用 |
|---|---|---|
| **放射式** | 一条线带若干台区，结构简单 | 最常见 |
| **环网式（开环运行）** | 两路电源互为备用，正常开环 | 城市中压配网主流 |
| **双电源（闭锁）** | 重要用户两路进线 | 重要负荷 |
| **单环网 / 双环网** | 提高可靠性 | 高可靠性区域 |

**注意**：说"环网"通常指**结构成环、运行开环**，
潮流上仍是放射状 —— 这点在算潮流时容易搞错。

### 0.4 kV 低压部分

| 方式 | 说明 |
|---|---|
| **三相四线制** | 动力与照明混合，最常见 |
| **单相两线** | 分散农户、单相供电 |
| **三相三线**（少见） | 仅动力负荷 |

### 配变接线组别

| 组别 | 说明 | 影响 |
|---|---|---|
| **Dyn11** | 高压三角、低压星形带中性点，11 点 | 常用；抑制谐波、承受不平衡能力强 |
| **Yyn0** | 高压星形、低压星形带中性点，0 点 | 曾大量使用；承受不平衡能力弱于 Dyn11 |

**Dyn11 优于 Yyn0 的原因**【待核，出自配变选型技术导则】：
三角形侧为零序谐波提供通路，低压侧单相负荷造成的零序电流不会串到高压侧。

**这对承载力有直接影响**：同一台区若用 Yyn0 配变，
三相不平衡的允许值要更保守（本工程用 GB/T 15543 的 2% 公共连接点口径）。

## 三、三相四线的特殊之处

### 中性线电流

三相不平衡时中性线有电流：

```
I_N = |I_a + I_b + I_c|   （相量和，三相平衡时为 0）
```

规程要求**中性线电流不应超过相线电流的 25%**【待核，出自低压配电设计规范实践要求】。

### 为什么低压不平衡影响这么大

1. 低压线截面小、`R` 大 → 不平衡造成的压降与损耗更大
2. 零序电流在中性线上产生额外损耗（`3·I_N²·R_N`）
3. 负载重相电压被拉低、轻相被抬升，**两头的用户都受影响**

### 单相光伏的特殊问题

户用光伏常单相接在某一相，会：
- 加剧不平衡（大发时该相被抬高）
- 反向潮流只走一相，中性线电流方向反转
- 可能导致**某相过压而另两相正常**

所以**单相接入的承载力往往受不平衡约束**，而不是受载流约束。

## 四、OpenDSS 里怎么建模（对应用户算例）

本工程算例的写法与对应关系：

| OpenDSS 写法 | 含义 |
|---|---|
| `New Circuit.X basekv=10.5 phases=3` | 三相电源 |
| `New Transformer.T1 phases=3 windings=2 ... wdg=1 conn=delta wdg=2 conn=wye` | **Dyn** 接线 |
| `New LineCode.LV_185 nphases=3` | 三相线路 |
| `New Load.LD1 bus1=LV_T1_N1 phases=3 conn=wye kv=0.4` | **三相平衡**负荷 |
| `New Load.LD_x bus1=LV_T1_N1.1 ... phases=1 kv=0.23` | **单相**负荷（接在 A 相） |
| `New Generator.PV_x bus1=... phases=1 kv=0.23` | 单相光伏 |

**母线名的 `.1` / `.2` / `.3` 后缀**表示接在哪一相
（`.1`=A 相、`.2`=B 相、`.3`=C 相）。

本工程三个桌面算例**全部按三相平衡建模**（`phases=3` + `conn=wye`），
所以不平衡度接近 0。要看不平衡，需要把负荷拆成单相。

## 六、台区级承载力的特殊性

台区承载力 ≠ 馈线承载力 ÷ 台区数。原因：

| 因素 | 影响 |
|---|---|
| 各台区负荷率不同 | 有的台区先满，有的还空 |
| 各台区低压线长短不同 | **低压线长的那台区先越限** |
| 各台区光伏规模不同 | 渗透率高的先出问题 |
| 配变容量不同 | 载流约束的余量不同 |

**这就是本工程「双台区对比」算例想说明的**：

| 台区 | 低压线 | 光伏 | 结果 |
|---|---|---|---|
| 台区1 | 0.15 km | 无 | 最低电压 0.9865，正常 |
| 台区2 | 1.60 km | 220 kW | 最高电压 1.1317，**越限** |

同一条馈线、同一时刻，两个台区结论完全相反。

## 七、排查台区问题时的入手点

1. **先看配变负载率**（是不是载流先满）
2. **再看最低电压在哪**（是不是末端）
3. **看低压线长度与截面**（R 大不大）
4. **看三相是否平衡**（单相负荷是否集中在一相）
5. 最后才考虑改造方案

本工程「算例分析 → 设备负载 / 电压校核」两页就是按这个顺序给的。
