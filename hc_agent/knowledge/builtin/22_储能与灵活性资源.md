# 储能与灵活性资源

储能在承载力评估里是**双面的**：
既是"能给网架加能力"的资源，也是"会改变潮流与电压"的接入对象。
本章把这两面都讲清楚。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、相关标准

| 标准 | 适用 | 说明 |
|---|---|---|
| **NB/T 33015-2014**《电化学储能系统接入配电网技术规定》 | 380 V / 10 kV 接入的储能 | 接入配电网的主要依据【已核对标准号与适用范围】 |
| **GB/T 36547**《电化学储能系统接入电网技术规定》 | 电化学储能接入电网 | 通用技术要求 |
| GB/T 12326 | 电压波动与闪变 | 储能接入点的波动和闪变值须满足 |
| GB/T 14549 | 谐波 | 变流器是谐波源 |
| GB/T 33593 | 分布式电源并网 | 储能常与分布式电源同场 |

储能接入点要校验的电能质量项与分布式电源一致：
**电压偏差、电压波动和闪变、谐波、三相不平衡**。

## 二、储能对承载力的两种作用

### 作用一：提升可开放容量

储能在**光伏大发时段充电**，把反向潮流吃掉，从而：

| 机制 | 效果 |
|---|---|
| 吸收反向功率 | 降低末端电压抬升 → 电压约束松绑 |
| 削减净倒送 | 反向潮流限值松绑 |
| 削峰 | 减少重载时段的载流压力 |

**关键前提**：储能的**功率与时长要匹配**。
只配小功率短时储能（如 0.5 h），对"连续 4 小时大发"没有实质帮助。

### 作用二：自身也要校验

储能接入同样是"新增电源/负荷"，要过同一套约束：
电压、载流、短路电流、不平衡。
充电时是负荷，放电时是电源 —— **两种工况都要算**。

## 三、容量与功率怎么配（常用思路）

中国工程上常见的配置思路：

| 目标 | 常见做法 | 备注 |
|---|---|---|
| 削峰填谷 | 按峰谷差的一定比例配 | 峰谷差见《负荷特性与同时率》 |
| 平抑光伏波动 | 按光伏装机的一定比例 / 一定小时数 | 常见 10%~20% 功率、1~2 h |
| 提升承载力 | 按越限时段的**能量缺口**倒推 | 需要先做时序潮流 |

【待核】上表是工程常见做法，不是标准规定。

**算能量缺口的正确方法**：

```
储能能量 ≥ 越限时段内「需要被吸收的反向电量」(kWh)
储能功率 ≥ 越限时段内「需要被吸收的最大反向功率」(kW)
```

不能只按"装机比例 × 时长"拍一个数，那样遇上连续阴雨转晴的工况就不够。

## 四、储能接入的技术要求（要点）

| 要求 | 典型值 | 可靠度 |
|---|---|---|
| 功率因数可调范围 | 超前 0.95 ~ 滞后 0.95 | 【待核】 |
| 变流器充放电效率 | 10 kV 接入 ≥ 96%；380 V 接入 ≥ 95%；220 V 接入 ≥ 94% | 【已核对，出自地方储能接入技术要求文件】 |
| 孤岛检测 | 必须具备 | GB/T 33593 |
| 通信与远方控制 | 具备可观可控 | NB/T 33015 |
| 消防与安全 | 按电化学储能电站相关规范 | 另行规定 |

**注意效率这一条**：储能不是"1 kWh 存进去 1 kWh 取出来"，
10 kV 侧接入按 96% 算，来回一趟（充+放）只剩约 92%。
算"能吸收多少反向电量"时必须用电网侧的**充电功率**，不是电池容量。

## 五、储能参与调压

储能通过**变流器无功**调压，响应快（毫秒级），但容量受限：

```
可调无功范围 ≈ ±√(S² − P²)      S = 变流器视在容量，P = 当前有功
```

所以满功率充放电时，**没有无功能力可用**。
这一点在"光伏大发、同时需要储能调压"的场景里会打架 ——
要么留功率余量，要么别指望它同时干两件事。

## 六、本工程怎么看待储能

| 项目 | 现状 |
|---|---|
| 潮流计算中 | 储能在 OpenDSS 里按 `Storage` 元件建，**按元件功率充放电**参与潮流 |
| 口径 | 端口 1 有功之和，**保留引擎原始符号**（正 = 充电、负 = 放电） |
| 容量搜索 | 本版**不把储能作为决策变量**（`caliber.unsupported` 已列明"自动分接头调压与无功补偿控制、拓扑重构、负荷削减、重调度"未覆盖） |
| 结论口径 | 给出的可开放容量是**不考虑新增储能**的结论 |

**回答"配多少储能能多接多少光伏"时**，必须说明：
本版不给这个数 —— 那需要把储能作为决策变量的优化，
而本工程当前做的是"给定配置下的承载力搜索"。

## 七、除储能外的灵活性资源

| 资源 | 提升承载力的机制 | 局限 |
|---|---|---|
| **需求响应** | 高峰时段压负荷，腾出容量 | 依赖用户意愿，可调量不稳定 |
| **无功补偿（SVG/电容器）** | 直接调电压 | 电容分组投切，调压有台阶；SVG 贵 |
| **有载调压配变（OLTC）** | 调低压侧电压 | 有档位限制、动作次数限制 |
| **柔性互联（SOP）** | 台区间功率互济 | 投资大，需两端都有余量 |
| **主动配电网重构** | 改变潮流路径 | 需开关自动化，运行约束多 |
| **调相运行/逆变器无功** | 光伏逆变器吸收无功 | 受功率因数范围限制，且牺牲有功 |

**这些手段本工程都只"识别不动作"**：可以在结论里提示，
但不会自动去调分接头或投切电容器（Agent 无任何设备写操作能力）。

## 八、常见误区

1. **以为储能能无限提升承载力**。储能功率、时长、效率都有限，
   而且充放电本身会让载流和短路电流问题变复杂。
2. **只看功率不看时长**。0.5 h 的储能挡不住 4 h 的大发。
3. **用电池容量当电网侧能量**。要除以效率、还要留 SOC 窗口。
4. **期望储能同时满功率放电又提供无功**。变流器容量摆在那里，二选一。
5. **忽略储能充电工况**。充电时是新负荷，可能让另一处载流越限。

- NB/T 33015-2014《电化学储能系统接入配电网技术规定》—— 能源行业标准
- GB/T 36547《电化学储能系统接入电网技术规定》
- GB/T 36276《电力储能用锂离子电池》—— 电池本体
- GB 51048《电化学储能电站设计规范》—— 站址、消防、布置
