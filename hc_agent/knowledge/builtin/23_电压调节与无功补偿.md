# 电压调节与无功补偿

电压是配网承载力**最常先到限**的约束。所以要能回答
"除了限制接入，还有什么办法把电压拉回合格范围"。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、电压为什么会偏

电压偏移的根本原因是**无功不平衡**与**线路压降**：

```
ΔU ≈ (P·R + Q·X) / U_n
```

- `P·R` 项：有功造成的压降（线路电阻）
- `Q·X` 项：无功造成的压降（线路电抗）

低压线路 `R` 大 → `P` 影响大（所以光伏有功会顶高电压）；
高压线路 `X` 大 → `Q` 影响大（所以高压侧靠调无功调压）。

**这条差异是回答"为什么低压侧调压要靠改接法、高压侧靠投电容器"的依据。**

## 二、调压手段一览

| 手段 | 调什么 | 响应 | 适用电压等级 | 局限 |
|---|---|---|---|---|
| **配变分接头（无载）** | 低压侧基准电压 | 停电手动 | 10/0.4 kV | 需停电，次数少 |
| **有载调压配变（OLTC）** | 低压侧基准电压 | 秒级 | 10/0.4 kV | 档位有限、动作次数寿命 |
| **并联电容器** | 无功（分组投切） | 秒~分钟 | 10 kV 母线/馈线 | 有台阶、过补偿会抬压 |
| **SVG / SVC** | 无功（连续可调） | 毫秒~秒 | 10 kV | 投资高、自身有损耗 |
| **逆变器无功** | 无功（光伏/储能变流器） | 毫秒 | 分布式电源接入点 | 受功率因数范围限制 |
| **调压器（串联）** | 线路电压 | 秒级 | 10 kV 长线路 | 需装设备、有容量限制 |
| **缩短供电半径/加大截面** | 线路阻抗 | 规划期 | 全电压等级 | 需改造投资 |

## 三、逆变器无功的边界（最常被高估的一条）

并网标准要求分布式电源功率因数能在 **超前 0.95 ~ 滞后 0.95** 可调（【待核】，见《并网与分布式电源标准》）。

由此可算无功能力上限：

```
S = P / pf  （pf = 0.95 时 S ≈ 1.053 P）
Q_max = √(S² − P²) ≈ 0.329 P
```

**即逆变器最多能提供约 33% 装机的无功**（在 pf=0.95 时）。
光伏 220 kW 最多约 72 kvar 无功。

这够不够压住电压抬升？用压降公式看：

```
ΔU_pu ≈ (P·R + Q·X) / U²
```

以本工程 `双台区对比` 算例的低压线为例（R≈0.158 Ω、X≈0.112 Ω、U=0.4 kV）：
- 反向 140 kW 纯有功：`ΔU ≈ 140×0.158/0.16 = 138 V` 量级（远大于允许值）
- 加 72 kvar 无功吸收：抵掉 `72×0.112/0.16 ≈ 50 V` 量级

**抵掉一部分，但远远不够。** 这就是为什么"让逆变器吸无功"不能替代
"缩短低压线"或"限制接入容量"。

## 四、电容器补偿的两个坑

**坑一：过补偿抬电压**

投入电容器时，若本地无功过剩，会**逆向**抬升电压。
光伏大发、负荷低谷时投电容，电压更容易越上限。

**坑二：分组投切有台阶**

比如 3×100 kvar 的电容器，只能投 0/100/200/300 kvar。
想要 150 kvar 就拿不到 —— 连续调节必须靠 SVG。

## 五、分接头调压的边界

配变分接头是**改变变比**，等效于把整个低压网络的电压平移：

- 好处：一次性解决一片区域的电压偏低；
- 局限：
  1. **档位有限**（常见 ±2×2.5% 共 5 档）；
  2. **无载调压要停电**；
  3. **平移不改变电压分布形状** —— 如果末端和首端差得太多，
     把末端调合格了，首端就过压了；
  4. 光伏大发时段需要**降压**，负荷高峰需要**升压**，两者相反。

**这就是"电压分布形状"比"电压平均值"更重要的原因。**

| 手段 | 本工程状态 | 说明 |

| 配变分接头 | **只识别不动作** | 潮流时按算例给定变比计算，不做自动调压 |
| 有载调压（OLTC） | **只识别不动作** | 同上 |
| 电容器/SVG 投切 | **只识别不动作** | 算例里固定的电容器按固定值参与潮流 |
| 逆变器无功 | **只识别不动作** | 按算例给定的功率因数计算 |

`caliber.unsupported` 里明确写了：
"自动分接头调压与无功补偿控制（本版只识别不动作）"。

**回答时的正确说法**：

> 本版不会自动投切电容器或调分接头，所以给出的承载力是
> "给定电压水平下"的结论。如果再加上调压手段，承载力可能更大，
> 但那个数本版算不出来。

**不要说**："只要调一下分接头就能多接 100 kW" —— 那是推算，不是本版结果。

## 七、电压问题怎么定位

排查顺序（从便宜到贵）：

1. **看哪一段线路阻抗最大**（R、X × 长度）—— 通常是低压线
2. **看越限时刻的潮流方向**（受电还是倒送）
3. **看是不是只有末端越限**（是 → 分布形状问题，调分接头没用）
4. 再考虑：改接法、加粗截面、缩短半径、加调压器、配储能

本工程的「算例分析 → 电压校核」页直接给出越限母线与偏离量，
「增减假设」页能试算把电源改到多少会越限 —— 这是定位问题的入手点。

## 八、常见误区

1. **以为调分接头能解决所有电压问题**。它只能平移，不能改变分布。
2. **以为逆变器无功能顶替增加导线截面**。无功能力约 33% 装机，量级不够。
3. **光伏大发时投电容器**。过补偿会让电压更高。
4. **只看平均电压**。配网电压问题几乎都在末端。
5. **把"电压合格"当成"承载能力足够"**。载流、短路、不平衡是另外三道门。
