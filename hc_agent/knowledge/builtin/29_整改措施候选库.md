# 整改措施候选库

承载力结论如果是"不能再接"，下一句通常是"那我能做什么"。
本章列出候选方向，**每条都写清触发条件、效果与局限**。

> **重要边界**：本章给的是**候选方向**，不是整改方案。
> 本工程不计算改造后的承载力（需要重新建模 + 容量搜索），
> 也不做经济性比较。实际方案需专业设计与人工审批。

## 一、按约束类型查

| 越限的约束 | 优先考虑 | 见本章 |
|---|---|---|
| 电压上限（过压） | 缩短低压半径 / 加粗截面 → 分接头 → 逆变器无功 → 储能 | §二 |
| 电压下限（压降大） | 加粗截面 / 加调压器 / 增大配变 | §二 |
| 载流（线路或配变过载） | 分流 / 增容 / 改接线 | §三 |
| 反向潮流超限 | 储能 / 限接入 / 需求响应 | §四 |
| 三相不平衡 | 调整单相接入相别 | §五 |
| 短路电流超限 | 专项校核后再定接法 | §六 |

本工程代码里的候选库编号是 `RM-V-01`、`RM-T-01` 等，与本章对应。

## 二、电压类措施

### RM-V-01 缩短低压供电半径 / 加大低压线截面

- **为什么有效**：低压线电阻是电压抬升（或压降）的主因，直接减小 `R`。
- **效果**：通常最有效。
- **局限**：需要改造投资与停电作业；若越限发生在中压侧，改低压线无效。
- **判断依据**：看越限母线是否在低压末端、低压线是否明显偏长（>600 m）。

### RM-V-02 调整配变分接头

- **为什么有效**：改变变比，整体平移低压侧电压。
- **效果**：成本低、见效快（无载调压需短时停电）。
- **局限**：
  - 只平移**不改变电压分布形状**；
  - 若末端合格后首端接近下限，抬压会引发首端低压越限；
  - 光伏大发要降压、负荷高峰要升压，两者矛盾。
- **判断依据**：看越限是否只集中在少数末端，且首端有足够余量。

### RM-V-03 逆变器吸收无功

- **为什么有效**：无功吸收抵消 `Q·X` 造成的压升。
- **效果**：零投资、可立即实施。
- **局限**：无功能力约 **33% 装机**（pf=0.95 时 `Q≈0.329P`），
  往往抵不掉长低压线的抬升；且牺牲有功出力。
- **判断依据**：先估算无功是否够。若越限 0.03 pu 而可调无功不足，就别指望它。

### RM-V-04 加装 SVG / 串联调压器

- **为什么有效**：连续可调无功（SVG）或直接抬升线路电压（调压器）。
- **局限**：投资高；SVG 自身有损耗；调压器有容量限制。

## 三、载流类措施

### RM-T-01 限制接入容量 / 分批接入

- **效果**：零投资、可立即执行。
- **局限**：这是"减少"不是"提升"，属于保守兜底。

### RM-T-02 配变增容或负荷分流

- **为什么有效**：直接提升设备容量，或把负荷分到相邻台区。
- **局限**：需停电施工；分流要看相邻台区是否真有余量。

### RM-T-03 改造线路截面 / 新建联络

- **效果**：显著提升载流能力，同时降低压降。
- **局限**：投资大、周期长，属规划级措施。

## 四、反向潮流类措施

### RM-C-01 配置储能吸收反向功率

- **为什么有效**：大发时段充电，削减净倒送。
- **效果**：同时缓解电压上限与反向潮流。
- **局限**：
  - 功率与**时长**都要匹配越限持续时间 —— 0.5 h 储能挡不住 4 h 大发；
  - 充电工况可能让别处载流越限；
  - 本版不给储能容量推荐值（那需要优化求解）。

### RM-C-02 需求响应（负荷侧）

- **为什么有效**：负荷低谷时反向潮流最严重，可通过增加本地消纳缓解。
- **局限**：依赖用户意愿，可调量不稳定。

## 五、不平衡类措施

### RM-B-01 调整单相接入相别

- **为什么有效**：把集中在一相的光伏/负荷分散到三相。
- **效果**：改动小、成本低。
- **局限**：需现场作业；效果取决于原有负荷的相别分布。

**注意**：不平衡判据有两个口径（公共连接点 2% vs 单个用户 1.3%），
整改前先确认按哪个口径判。

## 六、短路电流类措施

### RM-S-01 专项短路校核后再定接法

- **为什么**：逆变器型电源短路贡献约 1.1~1.5 倍额定，多点叠加可能超开关开断能力。
- **局限**：本版**不做完整短路计算**，只能提示需要专项校核。

## 七、怎么选（决策顺序）

```
1. 先看运维类：是不是开关没合、是不是能分流（零成本）
2. 再看零成本技术措施：调分接头、逆变器无功
3. 再看改造措施：加粗截面、缩短半径、配变增容
4. 最后考虑：储能、新建线路
```

每一步都要回到"**改造后能不能满足约束**"——但那个数本版算不出来，
需要用改造后的模型重新跑一次评估。

## 八、常见误判

1. **把"候选"当"方案"**。候选说的是方向，方案要设计。
2. **以为调分接头能解决一切电压问题**。它只平移、不改分布。
3. **以为逆变器无功能顶替加粗导线**。量级不够（约 33% 装机）。
4. **配储能但功率/时长不匹配**。挡不住长时大发。
5. **只改一处就以为万事大吉**。整改后要重新校核全部约束，
   否则可能把一个越限换成另一个越限。

## 九、怎么用这个库（在 Agent 里）

在对话里直接问：

```
电压越限了怎么办
这次的绑定约束能怎么整改
```

Agent 会读取当前运行的绑定约束与越限明细，
只为**真正触发了的约束**给出候选，并附上"为什么/效果/局限/依据"。

需要在「候选生成」权限下才能出候选（见《权限分级与技能契约》）。
