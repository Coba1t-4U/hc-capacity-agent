# 配电网规划与供电半径

承载力评估问"还能接多少"，本质是在问"这套网架还有多少余量"。
余量从规划阶段就定了，所以规划口径必须懂。

> 可靠度标注：【已核对】= 有公开正文或权威引用可交叉印证；
> 【待核】= 常见表述，引用前请以正式文本核对。

## 一、三条规划原则（配变的"小容量、多布点、短半径"）

这是配电网规划最常被引用的原则【待核，出自 DL/T 5729 与国网典型设计系列的表述】：

| 原则 | 含义 | 对承载力的影响 |
|---|---|---|
| **小容量** | 单台配变容量不宜过大 | 容量小 → 单点承载力低，但故障影响面小 |
| **多布点** | 配变尽量靠近负荷中心 | 低压线短 → 电压抬升/跌落都小 → 承载力更高 |
| **短半径** | 低压供电半径尽量短 | **最关键**：低压线阻抗是光伏顶高电压的主因 |

这条原则正好解释了本工程两个算例的差异：
`光伏高渗透`（低压线 1.6 km）电压先越限，`全部满足`（低压线 0.25 km）全绿。

## 二、电压降怎么算

线路电压降的工程近似（三项负荷、集中参数）：

```
ΔU ≈ (P·R + Q·X) / U_n          ΔU% ≈ (P·R + Q·X) / U_n² × 100%
```

- `P`、`Q`：流过该段线路的有功、无功（kW、kvar）
- `R`、`X`：该段线路电阻、电抗（Ω）
- `U_n`：线电压（kV）

**关键洞察**：`ΔU` 与 `P`、`Q` 成正比，与 `R` 成正比。
低压线 `R` 大（0.4 kV 下电流大、截面小、距离长），所以**低压线的 ΔU 往往占大头**。

### 用本工程算例验算

`配网承载力算例_双台区对比` 台区2：1.6 km 低压线、净外送约 140 kW。
- 0.4 kV 下 140 kW 对应电流约 224 A
- 2×0.9+0.7 km 的 R ≈ 0.158 Ω（0.099 Ω/km）
- 三相损耗 3·I²·R ≈ 23.8 kW —— 与报告实测 23.91 kW 吻合

**这就是为什么长低压线不经济**：不是电压问题，是损耗问题。

## 三、供电半径（量级参考）

| 电压等级 | 常见供电半径 | 备注 |
|---|---|---|
| 0.4 kV 低压 | 250 ~ 500 m | 负荷密度低的农村可更长，但损耗与电压问题明显 |
| 10 kV 中压 | 3 ~ 8 km | 与导线截面、负荷密度、允许电压降有关 |
| 35 kV | 20 ~ 50 km | —— |

【待核】上表是工程经验范围，**不是标准强制的统一数字**。
实际取值要按 `ΔU%` 允许值反算，且各地电网公司有各自的规划导则。

## 四、容载比

```
容载比 = 区域变电容量 / 区域最大负荷
```

常见取值（【待核】，各地口径不同）：

| 电压等级 | 容载比范围 |
|---|---|
| 220 ~ 35 kV | 1.8 ~ 2.2 |
| 10 kV 配变 | 约 1.5 ~ 2.0 |

容载比过低 → 一台主变检修或故障就限电；过高 → 设备利用率低、投资浪费。
**承载力评估里的"物理可开放容量"与容载比是两个概念**：
前者看电气约束（电压/载流/短路/不平衡），后者看容量备用。

## 五、导线截面怎么选

三个约束同时校核：

1. **载流量**：按环境温度、敷设方式、并列根数修正后的允许电流 ≥ 最大负荷电流
2. **电压降**：按允许 `ΔU%` 反算（GB/T 12325 的 ±7% / 本项目 0.90~1.10 pu）
3. **热稳定**：短路电流下的最小截面（DL/T 5222）

常见 10 kV 架空绝缘线截面：**95 / 120 / 150 / 185 / 240 mm²**；
低压电缆常见：**YJV 4×95 / 4×120 / 4×185 / 4×240**。

本工程算例用的型号：`LGJ-120`（10 kV 主干）、`LGJ-70`（分支）、
`YJV-4×185`（低压主干），分别对应 R1 = 0.270 / 0.450 / 0.099 Ω/km。

## 六、规划与承载力的关系（重要）

| 概念 | 回答什么问题 | 谁给 |
|---|---|---|
| 供电半径 | 这套网架该覆盖多远 | 规划导则（DL/T 5729） |
| 容载比 | 变电站容量够不够 | 规划导则 + 地方口径 |
| **可开放容量** | **现在这套网架还能再接多少 DG** | 承载力评估（本工程） |

**三者不能互相替代**：
- 容载比充裕不代表能接光伏（电压可能先越限）；
- 供电半径达标也不代表能接（可能载流先满）；
- 反过来，"可开放容量为 0"也不代表变电站容量不够。

## 七、本工程的口径对照

| 指标 | 规划口径 | 本工程承载力口径 |
|---|---|---|
| 电压 | 允许 `ΔU%` 按 GB/T 12325（10 kV 三相 ±7%） | 0.90 ~ 1.10 pu（项目批准值，比国标宽） |
| 载流 | 按修正后载流量 | 负载率 ≤ 100% |
| 反向潮流 | 规划一般不作为约束 | ≤ 400 kW（项目批准值） |
| 短路 | 选设备时校验 | ≤ 20 kA（项目批准值） |
| 不平衡 | 规划阶段不校验 | ≤ 2.0%（GB/T 15543 公共连接点口径） |

**回答"是否满足规划要求"时，要说明用的是规划口径还是承载力口径**，
两者电压限值本身就不同。

## 八、怎么核实

- DL/T 5729《配电网规划设计技术导则》—— 电力行业标准
- GB/T 12325-2008《电能质量 供电电压偏差》—— 见《国家标准限值速查》
- 国网/南网《配电网典型设计》系列 —— 企业标准，含供电半径与截面推荐
- 地方《配电网规划导则》—— 各省差异最大的一层
