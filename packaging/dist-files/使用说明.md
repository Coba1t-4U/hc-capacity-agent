# HC-Agent — 配网承载力与主配微协同优化 Agent

本目录是**自包含的桌面程序**，无需安装 Python 或任何依赖。

## 启动

双击 **`启动 HC-Agent.bat`**，或直接双击 `HC-Agent.exe`。

首次启动约 5~15 秒（要加载 OpenDSS 原生引擎）。

## 系统要求

* Windows 10 / 11，64 位
* 约 210 MB 磁盘空间
* 无需管理员权限

## 界面说明

| 页面 | 能做什么 |
|---|---|
| **运行总览** | 查看后端/引擎/看门狗/崩溃日志状态，以及最近一次评估结论 |
| **容量分析** | 选择输入包与输出目录，**真正发起一次评估** |
| **结果与证据** | 容量结论、求解口径声明、证据链门禁、独立复算 |

## 数据存放在哪里

安装目录**只读**。运行产物与日志写到：

```
%LOCALAPPDATA%\HC-Agent\
├── runs\           运行产物
└── logs\           日志与崩溃记录
```

想改位置就设环境变量 `HC_DATA_DIR`（例如放到 D 盘）。

> 如果该目录因权限策略不可写，程序会自动退到用户主目录或临时目录，
> 并在界面上如实显示，不会静默丢失结果。

## 排查

命令行可自检，输出为 JSON：

```
HC-Agent.exe --paths        # 查看各路径解析结果
HC-Agent.exe --self-test    # 检查可写目录 / 引擎 / numpy
HC-Agent.exe --version      # 版本
```

**引擎显示 0/3 不可用**：说明原生 DLL 未能加载。请确认整个文件夹
（含 `_internal\`）被完整复制，不要只拷 `HC-Agent.exe`。

**界面显示「未获取」**：后端还没起来或已崩溃，看
`%LOCALAPPDATA%\HC-Agent\logs\` 下的日志。

## 关于本程序的实现

* 界面用 **Tk 原生控件**绘制，**不是网页**：进程内没有 Chromium、没有 HTTP 服务、不监听任何端口；
* 计算引擎 OpenDSS 运行在**独立子进程**里，因此引擎中毒时可以被干净重启而不带走界面；
* 所有电气数值只来自 OpenDSS，界面不参与计算、不估算、不填充。
