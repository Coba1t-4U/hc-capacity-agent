# 对话独立运行（切页 / 切会话不打断）

## 一、要解决的问题

原来提问是在 **ChatView 里**起线程、算完调 `view.deliver()`。这带来三个真实问题：

| 场景 | 原来的后果 |
|---|---|
| 提问后切到「运行总览」 | ChatPage 控件被销毁，答案投给一个已死的视图 —— **消息直接丢了** |
| 提问后切到另一个会话 | 答案被插到**当前显示的那个会话**里 —— **张冠李戴** |
| 切页期间算完 | 用户看不到任何提示，回来发现什么都没有 |

## 二、现在的结构

把"算"和"存"从视图里提出来，放到 App 层的 `ChatRuntime`：

```
用户提问 ──▶ ChatRuntime.submit(session_id, q)
                │
                ├─ ① 立刻把用户消息写库（谁都不能丢）
                ├─ ② 后台线程算（规则引擎 / DeepSeek）
                ├─ ③ 算完把答案写库，**按提问时的 session_id**
                └─ ④ 若当前正显示同一个会话 → 顺带推一条气泡（已落库，视图不重复存）
                      否则什么都不做 —— 库里有，回来看得到
```

关键点：

- **结果以会话 id 归属**，不以"当前显示哪个会话"归属；
- 视图只负责显示，可以随时销毁；
- 用户消息**先落库再算**，所以即使算崩了，提问也不会丢。

### 界面上的表现

- 侧栏给正在算的会话加 **⏳** 前缀，算完自动消失；
- 切回正在算的会话时，对话区会提示"这个会话正在计算，答案算完会自动出现在这里"；
- 同一会话重复提问会被拒绝（不重复起算），不同会话可以并行。

## 三、改了哪些文件

| 文件 | 改动 |
|---|---|
| `hc_agent/desktop/chat_runtime.py`（新） | `ChatRuntime`：按会话提交、落库、投递 |
| `hc_agent/desktop/app.py` | 懒建 `chat_history()` / `chat_runtime()`；`ask_question` 改为投给运行时 |
| `hc_agent/desktop/chat.py` | `ask` 在 runtime 模式下直接提交（不再用 `_busy` 队列）；`_drain` 对已落库答案不重复存；`set_session` 时向运行时注册；`destroy` 时解绑 |
| `hc_agent/desktop/pages.py` | ChatPage 用 App 的共享历史库；侧栏 ⏳；`_poll_runtime` 轮询；进页时若会话在算就补提示 |

## 四、踩到的三个坑（都已修）

1. **视图换会话后仍登记在旧会话上**
   `bind_view` 只往 `_sinks[sid] = view` 里写，不清理旧条目。
   于是"A 会话算完的答案"会被推进"正在显示 B 的视图" —— 库里没错，但界面上串了。
   现在一个视图**只属于一个会话**，绑定新会话时清掉旧登记。

2. **runtime 模式下 `_busy` 永不清零**
   旧的 `_busy` 闸门是"单飞"模型：视图算、视图收答案、收到才 `_busy=False`。
   接了 runtime 后答案可能投给别的视图，本视图永远收不到，`_busy` 卡住，
   之后所有提问都被塞进队列再也出不来。现在 runtime 模式下**直接提交**，
   重复提交由运行时按会话拒绝。

3. **工作线程里调 Tk**
   `post_drop` / 运行时完成回调都在工作线程，直接调 `after()` 会抛
   "main thread is not in main loop"。所有"界面要跟着变"的地方都改成
   **主线程轮询**（`_poll_runtime` 每 700ms）。

## 五、验证

`tests/verify_chat_runtime.py` —— **31 项**：

**纯逻辑（不启界面）**
- 首次提交成功、提交后处于计算中
- 用户消息**立刻**落库（不等算完）
- 同会话重复提交被拒
- 算完退出计算中、答案落库（问+答 2 条）、角色/内容/引擎都正确
- 两个会话各自落库、空问题不提交

**界面（注入 1.2s 延迟，确保"还在算"能被观察到）**
- A：提交后处于计算中 → **切到运行总览** → 仍在算 → 切页期间算完 → 答案已写库 →
  切回对话页选中同一会话 → 页面上能看到提问与答案
- B：在 A 提问后**切到新会话 B** → 答案进 A（4 条）→ B 保持 0 条（不串台）
- C：侧栏出现 ⏳ → 算完 ⏳ 消失
- D：视图被销毁（切到配置页）后答案**仍然写库**，进程不崩

全量：**762 项通过 / 15 个套件 / 0 失败**。
