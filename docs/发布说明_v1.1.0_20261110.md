## 授权说明
1. 客户机器上取机器码：python -c "from hc_agent import license; print(license.machine_id())"
2. 供方签发：python tools\make_license.py --machine <机器码> --customer "XX" --expire 2027-12-31
3. lic.json 放程序根目录或 %USERPROFILE%\.hc_agent\
4. 无授权可启动，但容量分析被锁定（演示模式）

## 已知边界
- 授权为纯软件方案，防复制不防逆向；强保护需加密狗
- 系统级承载力用构造算例，不可作为真实区域结论
- IEEE-123 的 DG 容量扫描未完成（详见报告附录 A）
