## 四、已知坑（避免重复踩）

1. **Tk 不是线程安全的**：工作线程只能用队列回投，**不能**在工作线程调 `after()`，
   否则报 `main thread is not in main loop`。
2. **视图可能在使用中被销毁**（切页）：所有 `after` 回调先判 `winfo_exists()`。
3. **`ScrollArea` 只同步宽度会压扁内容**：`_on_canvas` 必须同时同步高度，
   否则 canvas 896px 而内嵌 frame 只有 68px。
4. **对话页/知识库页不能塞进滚动容器**：要 `FULLSCREEN = True`。
5. **`search_trace.csv` 的 `iteration` 不唯一**：粗扫描与二分各自从 1 编号，
   必须按 CSV 原始行序读。
6. **`SC` 不是时间场景**：短路校核，统计场景数时要排除。
7. **索引缓存要带分词器版本**（`TEXT_VERSION`），否则改了停用词仍是旧结果。
8. **BM25 不能按"当次最高分"归一**：只命中一个泛词也能拿满分，
   必须按查询词 IDF 总量归一。
9. **比较类词（区别/差异/对比）要进停用词**，否则会凭空命中。
10. **首次种子索引必须 `wait=True` 并真正阻塞**：否则进程退出时后台线程没跑完，
    用户首启看到空知识库（jobs 是 done 但 chunks=0）。
11. **截图用 `ImageGrab` 而不是 `PrintWindow`**：Tk Canvas 的显示列表不会重绘到离屏 DC。
12. **PowerShell here-string 会吃掉反引号与引号**：写含引号的 Python 脚本时
    会被转义坏，改用 write/edit 工具。
13. **`LOCALAPPDATA` 建目录可能被沙箱拦**：已用 `paths.data_root_safe()` 三级降级。
14. **后端回调不能整页 `_render_page()`**：会把 ChatView 重建、聊天记录全丢
    （现象是"提问后消息突然消失"）。有状态页面必须标 `STATEFUL = True`。
15. **`CalcVoltageBases` 必须放在所有元件定义之后**：提前算会让母线 `kVBase=0`，
    此时引擎返回的"标幺值"其实是伏特（6166 而非 1.017），电压判据全部失效。
16. **`CktElement.Powers()` 是逐端子逐相的**：两绕组变压器把两端都加起来会互相抵消；
    只取 A 相会少算 2/3。必须只取**送端前 nph 相**。
17. **网损不能用 `|源侧| − 负荷`**：光伏反送时会把倒送功率算进损耗。
    要用能量平衡 `源侧供给 + 分布式电源 = 负荷 + 网损`。
18. **`tk.Toplevel(self)` 挂 Frame 上会导致模态/定位异常**，要挂 `self.winfo_toplevel()`。
19. **截图前要按 PID 精确匹配窗口**：残留进程的窗口会被抓到，截出空界面误导判断。
20. **配置读取不能只认一个路径**：`data_root_safe()` 会降级，只认降级路径会出现"打包版读不到源码版写的 Key"。要按候选列表查找。
21. **`except: pass` 会吞掉 NameError**：`llm.py` 漏了 `Path` 导入，家目录兜底分支因此静默失效，表现成"候选位置少了一个"。边界分支里也要避免裸 `except`。
22. **表单里 `**` 不会被渲染**：原生 Label 不解析 Markdown，写进对话框会把星号原样显示出来。
23. **给外来对象起名要避开已有字段**：`ChatView` 的 `self._history` 已被输入框↑键历史占用，把 ChatHistory 存到同名属性会被列表覆盖，落库全部静默失败（会话条数永远是 0）。数据库请用 `self._db`。
24. **排序用的时间戳要带微秒**：秒级精度下"建会话+立刻发消息"会同时戳，`ORDER BY updated_at DESC` 退化成任意顺序，表现为"最新会话不在最上面""重开应用选错会话"。
