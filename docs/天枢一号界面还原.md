## 一、为什么直接对齐天枢一号的视觉

天枢一号的桌面端是一套**成体系的工程控制台**设计，不是随手写的样式表。
它有三个值得照搬的性质：

1. **深藏青侧栏 + 浅色内容 + 蓝色强调** —— 高对比但不刺眼，适合长时间盯着
   数值表；侧栏的实心蓝选中块给出明确的层级感。
2. **紧凑密度**（13px 基准、12.5px 表格、11~11.5px 元信息）—— 工程控制台
   要在一屏里放下尽量多的数，不是消费级应用的舒展排版。
3. **只用一套强调色** —— 全设计只有 `.app-icon` 一处渐变，其余是纯色；
   状态语义完全由「点 + 标签」的配色承担。颜色少反而让红/黄/绿更有信息量。

因此本工程**直接采用它的设计令牌**，而不是另起一套。

## 三、骨架结构

```
body                                  竖排：标题栏 → 状态栏 → 主体
├── header#titlebar        56px  grid 1fr auto 1fr，-webkit-app-region: drag
│     tb-left(app-icon + 折叠) / tb-center(标题) / tb-right(帮助·刷新·窗口按钮)
├── div#statusbar          36px  flex gap:18px
│     面包屑 | 后端 · 引擎 · 看门狗 · 崩溃日志 ……… 右侧：运行记录
└── div#app                flex, height: calc(100% - 92px)
      ├── nav#nav          220px 深藏青，一级导航（实心蓝选中块）
      ├── aside#subnav     224px #F2F5FA，二级导航（3px 左强调条）
      └── main#content     flex:1 → #page-body（唯一滚动容器，padding 20px 24px）
```

**要点**：`html,body{height:100%;overflow:hidden}` —— 页面本身**永不滚动**，
只有 `#page-body` 滚。这是"像桌面应用"而不是"像网页"的关键之一。

标题栏用 **grid** 而非 flex：`1fr auto 1fr` 才能让中间的标题在左右内容
宽度不对称时依然真正居中。

## 四、本工程的页面映射

天枢一号是「系统配置 / 分析工作台 / 结果展示」三页。本工程对应为：

| 本工程 | 对应天枢一号 | 二级导航 |
|---|---|---|
| **运行总览** | 系统配置 | 环境与就绪度 · 可靠性设施 · 引擎通道 · 运行记录 |
| **容量分析** | 分析工作台 | 如何发起一次评估 · 算例与场景 · 约束与阈值 |
| **结果与证据** | 结果展示 | 容量结论 · 求解口径声明 · 证据链与门禁 · 独立复算 |

## 六、刻意**没有**照搬的地方

| 天枢一号的做法 | 本工程的处理 | 理由 |
|---|---|---|
| `#inline-trace` 执行过程时间线 | CSS 已完整实现（`.exec-trace`/`.trace-step`），但本工程无逐阶段流式事件源，**不填假数据** | 没有真实事件流就不该画出"正在执行"的样子 |
| 无边框窗口 + 自绘窗口按钮 | 照搬（`frame:false` + `win:action` IPC） | 这是"桌面应用"而非"网页"的主要观感来源 |
| 聊天式会话队列 | 不做 | 本 Agent 是评估型而非对话型，套上聊天壳会误导 |
| 深浅色切换下拉框（实际无效） | 不做 | 天枢一号有控件但无深色样式表；不复制这种假选项 |
| `.foot`/`.form-row` 等无样式类 | 不复制 | 那是它的历史遗留；本工程不引入无定义的类 |

## 七、数据诚实性（比视觉更重要的一条）

界面**只读**，且遵循三条硬规矩：

1. 取不到就显示「未获取」，**绝不用 0 或估算值填充**；
2. `NaN`/`Infinity` 一律按「未获取」处理（有 `isFinite` 守卫）；
3. 数值带单位，口径写清楚（总负荷 ≠ 净负荷，见「求解口径声明」页）。

口径声明里的 `**加粗**` 是给 Word / Markdown 报告写的，网页端用 `md()`
转成 `<b>`，**不把星号原样显示**出来。

## 八、启动方式

```
# 桌面应用（Electron，自带后端托管与引擎自愈）
双击桌面「配网承载力 Agent」，或  cd hc_agent_ui && start-desktop.bat

# 仅后端 + 浏览器
python -m hc_agent.web         # 然后打开 http://127.0.0.1:8791/
```

**Electron 必须带两个参数**（实测 A/B 得出，缺一不可）：

| 参数 | 不加的后果 |
|---|---|
| `--no-sandbox` | 以 `0x80000003`（STATUS_BREAKPOINT）退出，**任何 JS 都不执行** |
| `--user-data-dir=<可写路径>` | 在 `app.getPath("userData")` 处 `0xC0000005`（访问违例）崩溃 |

这两个参数写在 `start-desktop.bat` 里，不由用户手输。
